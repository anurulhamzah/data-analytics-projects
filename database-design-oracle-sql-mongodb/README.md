# Relational and NoSQL database design

Individual and team work, Oracle SQL and MongoDB.

- `T2-pdc-insert.sql` to `T5-pdc-mods.sql`: schema population, queries and data modifications for a relational database.
- `T6a-pdc-json.sql`, `T6b-pdc-mongo.mongodb.js`: JSON handling in SQL and the equivalent in MongoDB.
- `vfc_schema.sql`, `vfc_schema_output.txt`: schema generated from a logical model built in Oracle SQL Developer Data Modeler (team of 3), with its script output.
- `vfc_model/`: the Data Modeler project files.
