# R data preparation and analysis case study

R Markdown report on a waste dataset: data preparation (structure checks, duplicate and missing-value checks, joins between tables), then analysis of waste by category, type, state and year (stacked bar charts of fractions, yearly trends, most recycled, most disposed and most increased waste types).

**Data not included.** The Rmd expects the source tables next to it.

**File:** `data_preparation_and_analysis.Rmd`.
