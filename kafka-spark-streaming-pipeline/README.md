# Real-time pipeline: Kafka and Spark Structured Streaming

Team project (team of 2), Python.

1. `1_producer.ipynb`: an Apache Kafka producer that simulates real-time data streaming.
2. `2_spark_streaming.ipynb`: a Spark Structured Streaming application that consumes the stream and computes windowed aggregates.
3. `3_consumer.ipynb`: a Kafka consumer that receives the processed results and visualises them.

Input data are not included.
